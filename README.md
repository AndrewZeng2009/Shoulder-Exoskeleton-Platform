# Shoulder Exoskeleton Platform
An open-source, low-cost (~$300) cable-driven shoulder exoskeleton designed as an accessible research and prototyping platform. Most existing shoulder exoskeleton platforms are expensive, proprietary, and inaccessible to small research groups, students, and independent developers. This platform addresses that gap by integrating established actuation and sensing technologies into a reproducible, modifiable system that can be fabricated with off-the-shelf components and a standard 3D printer.

The system combines a servo-driven Bowden cable transmission with passive bungee elastic assistance and a tri-modal sensor suite (surface EMG, IMU, and load cell) controlled by an Arduino Uno. An IR remote switches between off, sensor-only, and active assistance modes, with an adjustable EMG activation threshold. In a randomized two-session evaluation on one participant, combined active-and-passive assistance reduced mean medial deltoid EMG by 27.5–42.2% relative to the unassisted baseline across loads of 0–5 lb in flexion and abduction.

The target audience is the open-source community: students, hobbyists, and small labs who want to experiment with exoskeleton hardware, sensing modalities, and control algorithms without a large resource investment.

## Repository Structure

**CAD/**
- `native/` — Fusion 360 source files (.f3d, .f3z)
- `step/` — Universal CAD files (.step)
- `stl/` — 3D-printable components (.stl)

**Electronics/**
- `Simple Schematic.png` — Full wiring diagram

**Firmware/**
- `Shoulder_Exoskeleton_System_Code.ino` — Arduino control firmware
- `State Machine Diagram.png` — Control state machine diagram

**Data/**
- `trial_level_data.csv` — All 420 trials (both sessions) in run order: randomized order, motion, load, condition, mean and peak EMG, torque, ROM angles, and battery voltage after each trial
- `Shoulder_Exoskeleton_Data.xlsx` — Original analysis spreadsheet with formulas
- `README.md` — Column definitions

**Analysis/**
- `analyze.py` — Regenerates every statistic, table, and figure in the paper from `Data/trial_level_data.csv`
- `requirements.txt` — Python dependencies

**Results/** (generated by `analyze.py`)
- `emg_summary.csv`, `torque_summary.csv`, `rom_summary.csv` — Mean, SD, CV, and percent reductions (Tables 2–3, Figures 6–8)
- `interaction_emg.csv`, `interaction_torque.csv` — Passive × Active interaction with 95% Welch confidence intervals (Table 4)
- `effects_vs_baseline_welch.csv` — Each condition vs. baseline, including the harness-only (device burden) comparison
- `session_means_S1_vs_S2.csv`, `test_retest_summary.csv`, `pct_reduction_replication.csv` — Test–retest analysis (Table 5, Figure 9, Supplementary Table S1)
- `battery_voltage_summary.csv`, `torque_vs_battery_voltage.csv` — Battery voltage range and torque-vs-voltage regressions
- `latex_tables.tex` — Tables 2–5 in LaTeX

**Figures/**
- Figures 6–9 of the paper (PNG)

**Docs/**
- `BOM.md` — Bill of materials with sourcing and pricing
- `Assembly_Guide.pdf` — Step-by-step build instructions

## Getting Started
1. Print all STL components and source hardware per `Docs/BOM.md`
2. Assemble the platform following `Docs/Assembly_Guide.pdf`
3. Wire electronics per `Electronics/Simple Schematic.png`
4. Upload `Firmware/Shoulder_Exoskeleton_System_Code.ino` to an Arduino Uno
5. Open Serial Monitor at 115200 baud to verify all sensors

## Reproducing the Results
```
pip install -r Analysis/requirements.txt
python Analysis/analyze.py
```
Outputs are written to `Results/` and `Figures/`.
